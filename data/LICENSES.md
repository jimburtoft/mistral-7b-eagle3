# Data licenses

Every dataset used to build the training and evaluation sets for this draft is listed here.
Only the **first user turn** of each source row is used as a prompt. All assistant responses used
for training are **regenerated by the target model** (`mistralai/Mistral-7B-Instruct-v0.3`, Apache-2.0)
with greedy decoding (`data/regenerate.py`). No third-party assistant text is trained on.

| Source | HF id (revision) | License | Splits used | Prompts (train / test) | Use |
|---|---|---|---|---|---|
| UltraChat 200k | `HuggingFaceH4/ultrachat_200k` (`8049631c405ae6576f93f445c6b8166f76f5505a`) | MIT | `train_sft` -> train, `test_sft` -> test | 60,000 / 500 | general chat prompts |
| Magicoder OSS-Instruct 75K | `ise-uiuc/Magicoder-OSS-Instruct-75K` (`5f839b1f368a76b161028bb9edff055db34022b2`) | MIT | `train` (2 % hashed hold-out -> test) | 20,000 / 200 | coding prompts (`problem` field) |
| GSM8K | `openai/gsm8k` config `main` (`740312add88f781978c0658806c59bc2815b9866`) | MIT | `train` -> train, `test` -> test | 7,473 / 300 | math word problems (`question` field) |

Target model: `mistralai/Mistral-7B-Instruct-v0.3` (`c170c708c41dac9275d15a8fff4eca08d52bab71`), Apache-2.0.
Its outputs (the regenerated responses) carry no additional restriction.

## Rules
- Train and test prompts are deduplicated by normalized text; test prompts are selected first, so no
  test prompt appears in train.
- Not used: ShareGPT-derived sets (unclear license), Magpie / other sets whose responses were generated
  by models with restrictive output terms.
- Redistribution: the released artifacts are the draft weights and code. If the regenerated dataset is
  released, it ships prompt text from the MIT sources above (with this attribution) plus target outputs.
