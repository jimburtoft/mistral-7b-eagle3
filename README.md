# EAGLE3 speculative-decoding draft for Mistral-7B-Instruct-v0.3

An openly licensed [EAGLE-3](https://arxiv.org/abs/2503.01840) draft head for
[`mistralai/Mistral-7B-Instruct-v0.3`](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3), plus the
code that trained it. The code is device-agnostic: it was used to train on AWS Trainium2 and also runs on
CUDA GPUs and on CPU.

- **Draft**: one Llama-style decoder layer (hidden 4096) that reads the target's hidden states at layers
  2 / 16 / 29. The checkpoint uses the [speculators](https://github.com/vllm-project/speculators) EAGLE3
  format, so vLLM (`--speculative-config '{"method": "eagle3", ...}'`) and vllm-neuron load it unchanged.
- **Data**: openly licensed prompts only (UltraChat 200k, Magicoder OSS-Instruct 75K, GSM8K; all MIT).
  Every training response was regenerated by the target itself (greedy). See `data/LICENSES.md`.
- **Code provenance**: only public open-source code; see `THIRD_PARTY.md`.

## Layout

| Path | What |
|---|---|
| `eagle3/model.py` | EAGLE3 draft + training objective (TTT steps, forward KL on the draft vocab). Plain PyTorch, no flex-attention / Triton |
| `eagle3/target.py` | Frozen target forward (functional Mistral/Llama over the safetensors), returns aux + final hidden states |
| `eagle3/checkpoint.py` | Save / load in the speculators EAGLE3 format |
| `eagle3/device.py` | `--device auto|neuron|cuda|cpu`, `torch.compile` backend selection |
| `data/prepare_prompts.py` | Build the prompt set (dedupe, held-out test split) |
| `data/regenerate.py` | Regenerate responses with the target through any OpenAI-compatible server (vLLM on GPU, vllm-neuron on Trainium) |
| `data/pack.py`, `data/token_freq.py` | Tokenize + pack conversations into fixed-length rows; draft-vocab token frequencies |
| `train/producer.py`, `train/train.py`, `train/launch.sh` | Target-feature producers + draft trainer (file queue in `/dev/shm`) |
| `eval/acceptance.py` | Offline acceptance length (draft proposes k tokens at every response position) |
| `eval/serving/` | vLLM / vllm-neuron serving + `vllm bench serve` wrappers, GSM8K, greedy-identity checks |
| `tests/` | CPU parity against speculators (loss + gradients) and HF transformers (target), end-to-end CPU smoke |

## Quick start

CPU tests (no accelerator needed; `pip install -r requirements.txt speculators==0.9.0`):

```bash
python tests/parity_speculators.py   # our objective == speculators Eagle3DraftModel (loss, grads)
python tests/parity_target.py        # functional target == HF MistralForCausalLM
tests/cpu_smoke.sh python <regenerated.jsonl> <tokenizer_dir>
```

Training (one machine, N_PROD producer devices + 1 trainer device):

```bash
export ROWS="data_dir/rows/rows_*.npz" TARGET=/path/Mistral-7B-Instruct-v0.3 FREQ=data_dir/token_freq.pt EVAL=data_dir/eval
DEVICE=neuron train/launch.sh run1 20000 --accum 4 --lr 3e-4     # trn2.3xlarge: cores 0-2 produce, core 3 trains
DEVICE=cuda N_PROD=1 NDEV=1 train/launch.sh run1 20000 --accum 4 # single GPU: producer and trainer share it
```

Data (the target serves itself through any OpenAI-compatible server while responses are regenerated):

```bash
python data/prepare_prompts.py --out-dir data_dir/prompts
python data/regenerate.py --inp data_dir/prompts/train.jsonl --out data_dir/regen_train.jsonl --max-tokens 2048
python data/pack.py --inp data_dir/regen_train.jsonl --tokenizer $TARGET --out data_dir/rows --seq-len 2048
python data/token_freq.py --rows "data_dir/rows/rows_*.npz" --out data_dir/token_freq.pt
python train/producer.py --rows "data_dir/test_rows/rows_*.npz" --target $TARGET --eval-out data_dir/eval
```

Offline acceptance and serving:

```bash
python eval/acceptance.py --draft <ckpt dir> --target $TARGET --rows "data_dir/test_rows/rows_*.npz" --k 5
eval/serving/serve.sh mistralai/Mistral-7B-Instruct-v0.3 <ckpt dir or HF id> 3     # PLATFORM=gpu on a GPU
eval/serving/bench.sh eagle3 mistralai/Mistral-7B-Instruct-v0.3 prompts.jsonl 1 4 8
```

The trained draft and its evaluation are on Hugging Face:
<https://huggingface.co/jburtoft/Mistral-7B-Instruct-v0.3-EAGLE3>.

## Training recipe used for the released draft

One trn2.3xlarge (cores 0-2 produce target features, core 3 trains), 2,048-token packed rows, 4 rows per
optimizer step, AdamW (0.9, 0.95), bf16 autocast with fp32 master weights, grad clip 1.0, TTT 3:
1. 4,600 steps on the first 27k conversations, lr 3e-4 (warmup 200, cosine);
2. 6,000 steps on all 87k conversations from (1), lr 2e-4 (warmup 300, cosine to 15,000);
3. 9,000 steps from (2), lr 1.3e-4 (warmup 100, cosine), fresh optimizer state.
About 1.2 s per optimizer step (~5,000 loss tokens/s), ~6.5 h in total.
